# Malaysia Electricity Consumption Forecasting

BMMS2094 Statistics for Data Science

## Project
Comparative time series forecasting of Malaysia's monthly
electricity consumption in support of SDG 7.

## Dataset
Malaysia Monthly Electricity Consumption, 2018–2024.

## Forecasting Models
- Simple Moving Average
- Simple Exponential Smoothing
- Holt-Winters

## Evaluation
- MAE
- RMSE
- MAPE

## Software
R
